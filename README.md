# Quizarre_backend

## Структура репозитория
```
app/
    api/ - http роуты
    core/
        config.py - глобальные константы и переменные среды
        models.py - глобальные модели
        security.py - безопасность логина
    db/db.py - сетап базы данных
    models/
        user.py - модели, связанные с пользователем
```
